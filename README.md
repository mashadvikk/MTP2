## 1. НОД двух чисел (средняя 4)

НОД считается методом вычитания: пока числа не равны, из большего
вычитается меньшее (`while` + `if/else`). Отрицательные числа берутся по
модулю, НОД с нулём равен второму числу. `nod_many` находит НОД списка.
Ответ сверяется со стандартной `math.gcd`:

```
$ python nod.py
Первое число: 48
Второе число: 18
НОД(48, 18) = 6
Проверка math.gcd: 6
```

## 2. Калькулятор (средняя 6)

Меню из семи действий: четыре арифметических, степень, процент и корень
(`math.sqrt`). Действие выбирается цепочкой `if/elif/else`, ввод чисел
повторяется, пока не введено число (допускается запятая). Деление на
ноль и корень из отрицательного числа выводят сообщение об ошибке:

```
Действие: 4
x = 7
y = 2
Результат: 3.5

Действие: 6
x = 15
y = 200
Результат: 30.0

Действие: 7
x = -4
Ошибка: корень из отрицательного числа не определён
```

## 4. Игра «Угадай число» (повышенная 5)

Число загадывается `random.randint`, на каждую попытку выдаётся подсказка
«больше/меньше». Попыток даётся `ceil(log2(N)) + 1` — для 1..100 это 8:
столько хватает, если называть середину оставшегося диапазона. После
партии можно сыграть ещё, в конце выводится счёт.

```
Число от 1 до 100: 50
Попытка 1 из 8: загаданное число меньше
Число от 1 до 100: 25
Попытка 2 из 8: загаданное число меньше
Число от 1 до 100: 12
Попытка 3 из 8: загаданное число больше
Число от 1 до 100: 18
Угадала! Число попыток: 4
Сыграть ещё? (д/н): н
Партий: 1, побед: 1
```

## 5. Рекурсивная сумма (повышенная 9)

`rec_sum(n) = n + rec_sum(n - 1)`, базовый случай — `n <= 0`. Результат
сверяется с формулой Гаусса n(n + 1)/2. Рекурсией также считаются сумма
чисел отрезка `rec_sum_range(a, b)` и сумма цифр `digit_sum(n)`:

```
$ python rec_sum.py
n =   5: рекурсия     15, формула     15
n =  10: рекурсия     55, формула     55
n = 100: рекурсия   5050, формула   5050
n = 500: рекурсия 125250, формула 125250
Сумма от 3 до 7: 25
Сумма цифр 2026: 10
```

Глубина рекурсии равна n, а стандартный предел Python — около 1000
вызовов, поэтому в меню n ограничено 900.
